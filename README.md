# NeuroTone 🤖

AI-powered Telegram chatbot for real-time sentiment and emotional tone analysis using Python and NLP.

## Features
- Real-time sentiment analysis
- Telegram bot integration
- NLP-based text processing
- Lightweight and fast architecture

## Tech Stack
- Python
- TextBlob
- python-telegram-bot
- python-dotenv

## Installation

```bash
pip install -r requirements.txt
```

## Run the Bot

```bash
python bot.py
```

## Example

User:
> I love this bot!

Bot:
> 🙂 Positive
